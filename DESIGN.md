# TYROX Pharmacy & Polyclinic — Design notes

## Theme source
Colour system follows **PHOTO-3** (cream board + lime rail + forest type + medical cross bullets).

| Token | Value | Use |
| --- | --- | --- |
| Cream | `#F7F4EA` | Page + hero panel |
| Forest | `#006000` / `#0A4A0A` | Headings, dark bands |
| Lime | `#9BE000` | CTAs, accents, cross icons |
| White | `#FFFFFF` | Cards |

## Brand assets
- Site + hero logo: `images/TyroxLogo-hero.png` (from `TyroxLogo.pdf`)
- Social: [Facebook](https://www.facebook.com/tyroxpharmacy/) · [Instagram](https://www.instagram.com/tyroxpolyclinic/)

## Motion
Luxevia-inspired scroll system: directional reveals (`up` / `down` / `left` / `right`), staggered delays, lime image wipe masks, ken-burns hero slides, count-up stats.

## Layout inspiration
MuseCare medical landing pattern: hero split, care pillars, facilities board, consultants carousel, Google reviews band, visit CTA.

## SEO foundations
Local schema (`MedicalClinic` + `Pharmacy`), Open Graph, semantic sections, WhatsApp conversion paths, Google Maps + social sameAs.
